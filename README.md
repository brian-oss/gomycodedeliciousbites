his project is a basic **restaurant menu webpage** created using HTML.  

## Features
- Page title reflects the restaurant name.  
- Menu sections: Appetizers, Main Courses, Desserts.  
- Each section lists at least three items with names and descriptions using unordered lists.  
- Includes a link at the bottom to a contact page (placeholder).  

## How to View
Open the `index.html` file in a web browser to see the menu.
